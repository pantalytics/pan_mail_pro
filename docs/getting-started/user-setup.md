# User Setup

Each user who wants to send emails via Microsoft 365 needs to connect their account.

## Connect Your Microsoft Account

1. Click your **profile picture** (top right) → **My Profile**
2. Go to the **Mail Pro** tab
3. Click **Connect Microsoft 365**
4. Sign in with your Microsoft account
5. Grant the requested permissions

Once connected, a personal mailbox is automatically created for you.

## Set Your Default Mailbox

After connecting:

1. Go to **My Profile → Mail Pro** tab
2. Use the **Send from** dropdown to select your default mailbox
3. Click **Save**

The default mailbox is pre-selected when you compose new emails.

## Sending Emails

When composing an email in Odoo:

1. Open any email composer (from CRM, Helpdesk, etc.)
2. Use the **Send From** dropdown to select a mailbox
3. Compose your message
4. Click **Send**

Your default mailbox is pre-selected, but you can change it per email.

## Available Mailboxes

You'll see mailboxes based on your permissions:

| Type | Visibility |
|------|------------|
| Personal | Only you |
| Shared | All users (requires M365 SendAs permission) |
| Notification | All users |

## Disconnecting

To disconnect your Microsoft account:

1. Go to **My Profile → Mail Pro** tab
2. Toggle off the **Connected** switch
3. Click **Save**

This removes your OAuth tokens. You'll need to reconnect to send emails via Microsoft again.
