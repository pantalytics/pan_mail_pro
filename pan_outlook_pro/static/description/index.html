Why This Module?

This module solves common issues with Odoo's built-in email options:

Method Outgoing Incoming
Standard SMTP Requires insecure DNS settings No Graph API support
Odoo Microsoft Outlook App Sends from "notifications@..." Basic fetchmail only
Outlook Pro Correct From address Full 2-way sync

Setup Requirements

  1. Azure App Registration - Create a single-tenant app in Azure Portal
  2. API Permissions - Grant delegated permissions (with admin consent):
    • Mail.Send, Mail.Send.Shared (for sending)
    • Mail.Read, Mail.Read.Shared (for receiving)
  3. Configure in Odoo - Enter Client ID, Secret, and Tenant ID in Settings
  4. Connect Users - Each user connects their Microsoft account via My Preferences

Detailed setup instructions are provided in the Settings page after installation.

Data & Privacy

Data Disclosure

This module communicates with Microsoft Graph API to send and receive emails:

  • Outgoing: Email content sent to Microsoft for delivery
  • Incoming: Email content fetched from Microsoft and stored in Odoo
  • OAuth Tokens: Stored encrypted in your Odoo database (Fernet encryption)
  • No data is sent to the module author or any third party

All communication is directly between your Odoo instance and Microsoft's servers.

Technical Details
